# 来源索引与核实边界

本文件记录规则定位，不附教材扫描件或课件。本次已核实用户提供《互换性与测量技术》电子版封面、书名页和版权页：张铁、李旻主编，清华大学出版社，2010年12月第一版，ISBN 978-7-302-23988-8。本地正文PDF页码=印刷页码+12。此版本不是按2018/2022版标准编写，教材引用与现行性核查必须分开。

用户提供的《典型零件标注关键点（轴-齿轮-轴承）》为检索索引；“形状<定向<定位<尺寸”、三类导出轴线一概中径、固定未注公差等级等概括不能直接当作通用规则。与教材原文不一致时记录差异。

该索引还将外置箭头写为“从内向外指”，与两界线间区间为内的定义混淆；本skill用箭身内置/外置及尖端所向明确表述，见[条件规则](feature-decisions.md)。
