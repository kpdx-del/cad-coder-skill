# 标注对象、方向与范围的条件规则

适用于本skill的课程图和改错说明。先判定“版本→对象→项目→公差带→基准→连接→布局”，不要从箭头当前画在哪儿反推技术含义。先读[版本选择与差异](standards.md)；教材出处见[sources.md](sources.md)。下述旧教材方向表仅用于解释对应课程画法，不能代替1182—2018的规则。

## 1. 先分清对象与图线

| 名称 | 含义 | 例子及边界 |
|---|---|---|
| 组成要素 | 构成零件外形的表面，以及表面上的线 | 外圆柱面、孔壁、端面、圆锥素线；教材印刷54页 |
| 导出要素 | 从相应组成要素得到的中心点、中心线、中心平面 | 由孔壁得到孔轴线，由槽的两侧面得到中心平面；不是实物上的一条刻线 |
| 被测要素 | 本项公差所控制的对象 | 可以是组成要素，也可以是导出要素；“被测”不是“表面”的同义词 |
| 基准要素/基准 | 基准要素用于建立基准；基准是用于确定方向或位置的理想参考 | 把φ60孔指定为基准要素，由该孔建立基准轴线B。不要把图上任意点画线直接当成基准 |

“组成/导出”按结构特征分类，“被测/基准”按本项要求中的作用分类，两组不是互斥的四种要素。轴线直线度的对象虽为导出要素，却不因此需要基准。

尺寸线承载尺寸值和终端；尺寸界线把测量边界引到尺寸线；公差指引线连接框格和被测要素；基准连线连接字母框与基准三角形。使用者说“这条直线”时，先识别是哪一类。

## 2. 公差箭头的方向与落点分开判断

**1182—2018优先规则**：按第6章识别指向表面或导出要素，按§7.1的缺省规则及必要的方向要素/平面规定公差带。通常指引线方向本身不定义公差带；TED规定方向的情形除外。圆锥圆度按第15章、§17.4另标方向要素，辅助框格有指向主框格的箭头。径向方案与法向方案须明确选择。轴线两平面公差带还需按§7.3规定定向；φ不是所有轴线的固定前缀。

以下是用户2010版教材印刷57页及表3-3等的方向解释，**只在明确采用该教材画法时使用**。不能把“垂直被测表面”写成全部项目的通则，也不能只转动箭头就宣称满足2018版。

| 情形 | 方向与连接 | 依据/限制 |
|---|---|---|
| 平面平面度等，公差带为两平行平面 | 沿带宽方向，通常垂直被控名义平面；箭头落在其轮廓或延长线上，与尺寸线错开 | 表面控制；教材图3-9、表3-3 |
| 圆柱面的圆度、圆柱度，径向圆跳动 | 径向指示；在轴向视图中垂直轴线，也垂直圆柱素线 | 不因图中有轴线就把其他箭头全部转成径向 |
| 圆锥面的圆度（旧教材示例） | 按相应圆截面的径向指示，在轴向视图中垂直轴线 | 表3-3；2018版须另给方向要素，不能仅靠这根箭头 |
| 圆锥面的斜向圆跳动 | 沿规定检测方向；教材常见方案垂直锥面素线，若明确给定检测角度则按该方向 | 印刷81页；不能简单改成径向 |
| 端面圆跳动 | 轴向指示，平行回转轴线、垂直名义端面 | 印刷81页 |
| 孔/轴的轴线、槽的中心平面 | 指引箭头与相应尺寸线对齐，借尺寸识别导出要素；方向相同可共用尺寸箭头 | 图3-10。普通直径尺寸在轴向视图中垂直轴线，但不能因此把箭尖直接画在任意中心线上 |
| 圆锥轴线 | 按圆锥相应尺寸识别轴线；按教材图3-11处理，必要时补空白尺寸线 | 不能套用圆锥表面的法向箭头 |

同一要素、同一指示/检测方向的多项要求可叠框共用指引线；不同方向分开。公差带为圆/圆柱才在相应值前加φ；不按“零件是圆的”统一添加。

## 3. 基准连线与尺寸线重合或错开

| 需要建立的基准 | 连接方式 |
|---|---|
| 平面、边线等组成要素形成的基准 | 三角形底边贴对应轮廓或其延长线；与相关尺寸线明显错开，避免误认成中心要素基准 |
| 轴线、中心平面等中心要素形成的基准 | 基准连线与对应尺寸线共线/对齐；不直接指向任意图示中心线 |
| 圆锥轴线基准 | 教材图3-13(c)：连线垂直轴线，三角形的底边/短横线平行圆锥素线；连线与素线不是同一个方向 |

教材图3-13允许基准符号代替其中一个尺寸箭头，是“可以”，不是自动删除箭头的命令。保留普通尺寸箭头时，箭身在尺寸区间内、基准三角形在界线另一侧，避免图形面积重叠；采用替代时核对实际三角形和接触位置。当前课程图优先保留可辨识的普通尺寸双箭头；需要替代/共用时明确每个端点的符号归属，不能把NONE写进预期后自动算合格。

黑色实心三角形是用户已选画法；17851—2022 §7.2.1允许填充或空白三角形。基准代号采用矩形框；§7.2.2不宜使用I、O、Q、X，P允许，不能沿用旧教材的九字母禁用表。基准字母框不是公差框格，连线不要穿入字母框。

## 4. 哪些线伸出，哪些线到连接处结束

| 图线 | 端点规则 |
|---|---|
| 尺寸界线 | 越过尺寸线终端，保留清楚的伸出段。清华出版社制图教材示例为约2 mm；本项目遇到三角形时还应覆盖整个底边并留净距，不能停在底边中点 |
| 轮廓的细实线延长线 | 用于连接基准或公差箭头时，本项目优先使连接点处在短延长线内，避免在三角形底边中点截断；不得改变实际零件几何 |
| 真实零件轮廓 | 在真实边界处结束；不能为了美观把端面或外形任意拉长。要延长的是辅助细实线 |
| 公差/倒角指引线 | 到箭尖与被指位置、框格连接边界为止；不能穿过被测位置，也不能插进框格内部 |
| 基准三角形与字母框之间的连线 | 从三角形尖端连到字母框边界为止；不是本项目要求继续伸出的尺寸界线 |
| 尺寸线 | 与尺寸箭头按原生几何衔接；外置箭头时保留所需外侧线段。不能把尺寸界线的伸出规则套在全部尺寸线上 |
| 轴线/中心线 | 适当伸出零件轮廓，保持规定线型；避开文字、框格和其他符号 |
| 剖面线 | 裁剪在材料边界内，不越过轮廓、孔和槽 |

原生尺寸以DIMEXE控制界线越过尺寸线的长度，DIMEXO控制起点间隙，两者不同。本题采用6 mm是具体布局选择，不是所有图样必须6 mm。允许的界线起点间隙、文字避让和点画线节奏不要误报成漏线。

## 5. 哪些项目有基准

按教材印刷54页表3-1：

| 项目 | 基准要求 |
|---|---|
| 直线度、平面度、圆度、圆柱度 | 主公差框格无定位基准；不能给孔轴线直线度随意加B。2018版辅助相交/定向平面或方向要素可引用基准规定方向，应与主框格区分 |
| 平行度、垂直度、倾斜度 | 有基准，用来确定方向 |
| 同轴度/同心度、对称度 | 有基准，用来确定相对位置 |
| 圆跳动、全跳动 | 有基准，建立回转基准轴线 |
| 线轮廓度、面轮廓度 | 有或无；依规范是否控制相对基准的方向/位置判断 |
| 位置度 | 有或无；不能把“位置度”直接翻译成“必须补A/B/C”。须核对完整的理论正确尺寸及成组规范 |

基准是功能、装配、加工和检验方案的选择，不是为了填满框格。缺少功能信息时询问。没有基准的形状公差不等于缺一栏；有基准的项目也不是必须填三个字母。

## 6. 尺寸箭头的内外方向

“内/外”以下均相对两条尺寸界线之间的测量区间，不是相对零件材料：

```text
箭身内置：   |◀────────▶|      从区间内指向两侧界线
箭身外置： ──▶|        |◀──    从区间外指向两侧界线
```

1. 两箭头与完整尺寸文字组有空间时，通常箭身内置。
2. 文字放不下但箭头放得下，可以文字外置、箭头内置；不是“文字外置必然箭头外置”。
3. 箭头也放不下时采用外置箭身、尖端朝向尺寸界线；本项目在自动选择窄尺寸/外置文字方案时，沿用用户确认的此项默认。
4. 按实际字体、偏差堆叠、符号、箭头大小和净距判断，不能只数文字字符。箭头位置与文字位置分别处理。
5. 上述是普通线性尺寸的两端规则。半径、单独指引线、只画一半的对称图形等另按其规则处理，不能一律检查为两个普通箭头。

依据：清华出版社《画法几何及机械制图》试读§1.1.5、表1-5，链接见sources。原用户索引中“箭头外置、从内向外指”的表述方向混淆，不沿用。

## 7. 倒角的几何、标注和覆盖范围

- 45°倒角可用`2×45°`，2是倒角的线性尺寸，不是数量；C2也是45°倒角的简写。非45°倒角用明确的线性尺寸及角度表达，不把所有倒角都写成C。
- 连续圆周棱边（轴端外圆或孔口）倒角后形成一整圈倒角面；主视图上下两处轮廓都要表现对应斜边，一处清楚标注可说明同一圈，不必上下各重复标一次。
- 一圈倒角不自动包括另一轴端、孔口内圈、轴肩另一棱边、键槽或其他独立边；这些是不同的倒角范围。棱柱上一个局部角也不能自动推成“全周”。
- 要求多个独立边全部倒角时，每个范围必须被完整覆盖：逐处标注，或对相同倒角用明确数量/分组引出合注，或以范围清楚的统一技术要求表示；不是强制每个角各画一根箭头。
- 需要表达的倒角轮廓应与规定范围一致，不能只改标注文字却保留错误尖角。采用允许的简化画法时说明依据；本项目的旋转轴主视图不得一侧有斜边、另一侧仍保留原尖角。
- “全部”仍须明确大小、角度及范围。只有“全部倒角”但没有尺寸时，不能自动补C1或C2。示例文字“未注倒角0.5×45°”仅说明表达形式，不能作为用户零件默认技术要求。
- 本项目带箭头的倒角引出段沿真实倒角直线的延长线，箭头指向真实倒角；尺寸文字放在水平段上方。这是已确认默认，不把标准允许的其他明确尺寸注法一概判错。
- 倒角应裁剪原两条轮廓并生成真实斜边；尺寸界线从实际轮廓取落点，不能继续指向已被切掉的旧角点。特殊规定的理论交点尺寸另按规定表达，不与错误的悬空界线混同。

## 8. 自动化实现边界

这些是已核实的条件规则，不等于现有脚本已实现全部语义判断。当前独立箭头检查和部分连接检查可用；圆锥径向/法向选择、基准是否适用、整圈和全零件倒角范围等，需明确对象/方向/范围信息后才能自动核对。不能仅根据截图线段猜这些信息。
