# 协作方式

本项目（cad-coder skill）由 Codex 与 OpenCode + DeepSeek V4 Pro 分工实施。本文件只记录当前协作约定，不修改任何全局配置。

## 分工

- **Codex**：澄清需求、拆分方案、划定范围、规范验收，并做独立审查（另起环境独立运行测试与目视核对）。范围、技术判断与最终接受由 Codex 决定。
- **OpenCode + DeepSeek V4 Pro**：作为唯一实施者，具体编写代码、整理文档、执行测试并如实报告。

## 轮次与范围

- 默认至多 3 轮；验收通过提前结束；轮询/澄清不计入轮次。
- 每轮开始明确允许修改的文件清单与只读范围；实施者不得越界。超范围变更先停止该部分并返回 Codex，不自行扩大。

## 实施者交付

实施者每轮报告：真实修改文件列表、关键设计、实际执行的命令与结果、剩余限制/疑问、任何未运行的检查。未成功的命令如实报告。执行日志、临时输出与总结只写入约定的本轮目录（如 `.local/deepseek-round1/`）。

## 约束

- 不同时修改同一文件；不递归委派或启动其他 Agent。
- CAD 专业数据不猜测：关键公式、尺寸、直径/半径等独立核算；技术数值与预览不擅自改动。
- 陌生零件先查 GitHub 成熟库，再依适用国标/教材核验；拟建的二维零件库记录来源、版本和验证状态。不写“所有零件库已实现”。
- 渲染与视觉结果需审阅；图纸最终上传前必须经用户确认。
- 测试数量、性能测量只记录实际值，不写死、不冒充图纸标准合规。
