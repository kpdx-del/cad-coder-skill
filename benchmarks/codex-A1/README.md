# CASE-A1: Codex 三模型同题试画
[匿名图纸（按 01、02、03 排列）](compare.pdf) · [作者对照](authors.md)

各组独立读取同一份 input.md，使用相同的高推理设置、Python / ezdxf 环境与三次运行预算。每组目录包含源代码、可编辑 DXF、PDF 和预览。教学测试数据，非制造图。

| 模型 | 输入 tokens（含缓存） | 其中缓存输入 | 输出 tokens（含推理） | 总 tokens | 会话用时 |
|---|---:|---:|---:|---:|---:|
| GPT-6 Astra | 950238 | 885632 | 7221 | 957459 | 6分46秒 |
| GPT-6.1 Sol | 995206 | 925056 | 6287 | 1001493 | 5分40秒 |
| GPT-6.2 Astra | 832210 | 775296 | 4523 | 836733 | 5分23秒 |

数据取自每个独立绘图会话的累计 token 计数。时间从会话创建到任务完成，包括读资料、写代码、渲染和审图。结果只代表这一题。01 的槽宽文字与中心线重叠，箭头检查不能发现这一类错误。check_slot_text.py 提供针对本题的专项检查；slot-check.json 也保留了本地历史对照的实测值。绘图脚本需要将仓库 scripts 加入 PYTHONPATH 并安装所用字体。
