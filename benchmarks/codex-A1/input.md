# CAD-Coder：机械零件工程图加强版

Based on [alexzeng2014/cad-coder-skill](https://github.com/alexzeng2014/cad-coder-skill), secondarily developed by kpdx-del. Preserve upstream MIT license and attribution. This derivative adds engineering annotations, parameter preflight and evidence-based correction; it is not a universal standards-compliance engine.

## 先明确，再绘图

1. 读取本次附件、现有脚本/DXF、参数及对话，确认草图、正式图或改错。已知信息不重复问。
2. 先按[标准版本规则](references/standards.md)：明确指定版本则服从题设；未说明则查询并采用已实施且现行的最新版，核对注日期/不注日期引用。再按[输入规则](references/inputs.md)选择课程/通用工程模式，只询问影响交付的缺失参数，每轮1—3项。按[六类专项](references/parts.md)识别条件必需项。
3. 所有技术值记录用户给定/查表/计算/已确认建议的来源。禁止按图片比例猜精确值，禁止自动补材料、配合、公差、粗糙度等。条件不足只能交显著标记的草图，不能伪装正式图。
4. 正式生成前调用 `drawing_checks.assert_ready(spec)`，确认独立尺寸、功能和基准。先按[条件规则](references/feature-decisions.md)区分组成/导出要素、指示方向、基准有无及倒角覆盖范围，再采用[通用标注规则](references/annotation-rules.md)和当前类别专项；不机械套所有几何公差。
5. 生成并执行Python builder，保存DXF，重新读取并检查，再渲染整图与拥挤细节。修复后重复受影响检查；报告未覆盖的人工复核项。

来源索引及适用边界见 [sources.md](references/sources.md)。教材和指定/现行标准有差异时按条款说明，不把旧教材或项目偏好冒充唯一国标。教材第三章辅助解释连接关系，示例数值不能套入用户零件。

涉及螺栓、螺母或装配配合归属时，读取[紧固件画法](references/fasteners.md)：区分头部端视、螺纹端视、内外螺纹及轴向装配剖切；表示法标准与产品尺寸标准分别核对。

涉及螺栓、螺母、垫圈、单列圆锥滚子轴承、平键、隔套的二维画法、参数来源或审图规则时，先按[二维零件库](references/part-library.md)离线检索（`python scripts/part_library.py list/search/show/check`）：只报真正缺项/条件待确认，不填数值、不改输入；官方标准目录状态不等于尺寸表已核验，未核验尺寸不能标成正式尺寸库。

## 实现约定

FreeCAD二维导入、批量渲染、缓存与SolidWorks环境探测时，按需读取[CAD后端](references/cad-backends.md)。原生文件、导入实体和参数化特征树分别报告；未实际验证的软件能力不能宣称已支持。多格式预览优先调用`render_many()`，保留`render()`兼容接口。

- 毫米、R2010、模型1:1、dimlfac=1。图幅/打印比例与几何尺寸分开。图框标题栏按指定格式，放不下应调整布局或图幅，不静默缩小。个人字段缺失留空。
- `new_doc()` 创建 CAD_TEXT=ISOCP、CAD_CJK=仿宋，普通字3.5 mm、偏差2.5 mm。字体须安装或通过 CAD_FONT_DIRS 定位；禁止静默替换，不附字体。独立文字用 `typography.add_text`，不要漏样式。
- 轮廓0.50 mm；THIN、DIM、CENTER、HIDDEN、HATCH 0.25 mm。轴线点画、轮廓连续、键槽中心线伸出两端，剖面线裁剪到材料。
- 尺寸使用原生DIMENSION；公差框格是可编辑线/文字，不冒称原生TOLERANCE。图元可编辑不等于所有CAD软件重排一致。
- 箭头验收独立于生成样式：先明确各端的普通箭头或合法替代。要求普通箭头时，重读DXF调用`audit_annotations(msp,required_arrows={尺寸handle:(1,2)})`；禁止因脚本写了NONE就修改验收预期。见[防漏检查](references/checking.md)。
- 引出线优先直线或一次转折。框格默认左边中点进入、末段水平；倒角有箭头段与真实倒角延长线共线。黑实心基准三角形底边贴边界，不能用普通箭头替代。
- 表面公差连接与尺寸线错开；导出要素与对应尺寸线对齐，可共享箭头。φ由公差带形状决定。尺寸外置保持完整偏差组，不能缩字挤入。
- 不把旧教材的箭头方向当作2018版的通用公差带定义。圆锥圆度按1182—2018第15章和§17.4补方向要素；辅助方向框格可有基准引用，不等于圆度主框格有定位基准。详见版本规则。
- 总长和全部分段不同时作为独立约束。先保功能尺寸，省略经确认的可推导非功能尺寸；不自动删最短环。公称差值与公差区间分别计算。
- 剖切位置与断面中心使用同一定位来源，检查共线及上下标识对称。先预留标题栏和整组标注范围，再排文字/引线；粗糙度与剖切符号不能共用笔画。关联和分组写入CAD_LAYOUT，随DXF保存。
- 倒角或圆角移除了原始角点时，尺寸界线必须重新关联实际轮廓，不能只把extension_gap设为0。`dim_linear(...,witness_geometry=contour)`记录来源并检查落点；当前自动支持直线和无圆弧段多段线，其他轮廓明确列为复核。

## 辅助函数

安装 requirements.txt，将本skill的scripts目录加入Python导入路径。模板默认值仅为演示，不能作为用户零件参数。

- `new_doc(text_height=3.5,font="isocp___.ttf",*,cjk_font="simfang.ttf",extension_gap=1.0)`：本示例显式选extension_gap=0贴轮廓起线；不将允许的起点留白一概当断线。
- `dim_linear(msp,p1,p2,offset,angle=0,text=None,*,upper=None,lower=None,text_location=None,suppress_arrow=None,arrows="auto",reference=False,text_side="above")`：正offset水平向下、竖直向左。text="%%c<>"保留测量并加直径。upper/lower成对且有符号。arrows支持auto/inside/outside。text_side=above按完整MTEXT排版范围保证文字在水平线上方/竖直线左侧，native保留原生位置。suppress_arrow=1/2仅用于明确替代；需要双箭头时另布置基准，不能同点叠加。
- `dim_diameter`、`dim_radius`、`dim_angular`：原生尺寸；`tolerance_text`仅为独立堆叠MTEXT，不是测量尺寸。
- `leader`、`chamfer_note(...,chamfer_edge=(p1,p2),target=...,elbow=...)`：原生LEADER从箭尖开始，倒角函数校验共线，标注2×45°。
- `roughness_symbol(...,method=None,lay=None)`：课程图5-10布局，Ra在长横线下、方法在上；旋转整体符号。
- `datum_symbol(...,side="below",filled=True)`：三角形底边贴边界；轴线基准调用者负责尺寸线对齐/箭头替代。
- `feature_control_frame(...,target=None,elbow=None,arrow=True,zone=None,feature=None)`：支持symmetry、cylindricity、circular_runout、flatness、roundness、coaxiality、perpendicularity、parallelism；实际字宽定格宽，最多三基准格。zone=circle/cylinder/sphere按声明加φ/Sφ，feature保存表面或导出要素信息用于检查。`frame_leader`连接已有框格。
- `audit_annotations(msp)` 保留字符串问题列表。更全面检查用 `drawing_checks.audit_drawing(msp,chains=...)`；输入预检、尺寸链与区间计算见引用文档。
- `cutting_marks` 生成上下镜像标识并返回定位图元；`section_axes(msp,cut,cy,radius,label)`从真实剖切图元取位置，生成共线中心线及居中名称。`drawing_layout.choose_position`在有意义的候选位置中避让整组范围；无位置则报错重排，不随机绕线。

## 改错与交付

见[检查与改错](references/checking.md)。脚本修生成逻辑；DXF修订副本；截图只诊断已知信息。给出位置、依据和修改记录。排版可修，改变技术数值/基准/配合/功能尺寸须有依据或确认。`repair_dxf.py`只自动修字体样式，不能把全部报告项称为已修。

渲染：`python scripts/render_dxf.py part.dxf part.png`；固定图幅 `part.pdf --paper A3 --scale 1`（A4亦支持，--scale 0.5表示1:2）。预览保留字体填充轮廓的绕向，解决Ø错误填充，不再用空心描边替代所有字体。字体缺失/字形不全/图幅溢出明确报错。

交付DXF、builder、PNG/PDF及检查结果；图片不能替代可编辑CAD。只有实际在某CAD软件打开/编辑过，才能声称该兼容性已验证。

修改后运行 `python -m unittest discover -s tests -v` 和skill-creator的quick_validate；执行examples/engineering_annotations.py，重开DXF检查，并看整图和局部。自动检查不等于全标准合规，测试数量不是验收结论。

### inputs.md
# 绘图前询问与输入约定

先读附件、现有 DXF、脚本、参数表及对话，列出已知条件，只问当前必需而缺失的信息，每轮1—3项。不要重复询问，不增加终端问卷。

## 模式与参数分类

- 版本优先级见[standards.md](standards.md)：指定版本优先，未指定默认已实施且现行最新版。课程模式不自动把旧教材版本作为默认标准；比较差异需具体出处。
- `course`：记录作业要求、教材和教师要求；冲突列出并澄清，不能自称某教材版式代表所有现行国标。
- `engineering`：记录标准名称及版本；无法取得原文的规则标待核实，不能猜接口或公差值。
- 必需：唯一确定当前几何、正式标注及输出所需的数据。
- 条件必需：存在对应特征或用户要求设计配合时才需要。
- 可选：姓名、学号等留空；不存在的结构不询问，未要求的加工说明不增加。
- 设计建议：与已给条件分开，说明来源，确认前不能成为正式制造要求。

## 脚本预检

`drawing_checks.assert_ready(spec, formal=True)` 在正式生成前运行。下面为结构示意，参数必须来自本次请求；示例数据不得作为用户零件默认值。

```python
spec = {
    "mode": "course", "part_type": "shaft", "units": "mm",
    "references": ["用户指定教材：版本与定位信息"],
    "parameters": {
        "diameters": {"value": [30, 40, 25],
                      "source": {"kind": "user", "statement": "本次请求明确给定的轴径"}},
        "axial_dimensions": {"value": [40, 35, 125],
                             "source": {"kind": "user", "statement": "两端功能长度及总长"}},
    },
    "required": [], "conditions": {},
}
```

通用入口：`validate_inputs(spec, formal=True)` 返回结构化问题；`assert_ready` 遇到 error 抛出 ValueError。`required` 补充具体零件的必需参数名，基础类别清单不能证明几何已唯一确定。嵌套特征要分别列入必需清单或人工逐项核对。

`parameters[name]` 包含 `value` 与 `source`；偏差可含成对的 `upper/lower`（有符号，upper≥lower）。来源种类：

| kind | 必需记录 |
|---|---|
| user | statement：本次给定条件或附件定位 |
| reference | document、edition、locator：文献、版本、页/表/行 |
| formula | expression、inputs：表达式、已提供的输入参数名；程序不执行任意表达式 |
| proposal | reason、confirmed：建议依据，明确确认后才允许正式出图 |

不根据图片比例推算精确尺寸；不默认补材料、热处理、载荷、配合、公差或粗糙度。来源字段只是追溯记录，不证明内容真实；仍须核对原文和计算。

## 草图与正式图

缺少条件时允许 `formal=False` 草图：只画能够确定的几何，省略未知特征，显著标“草图／条件待补齐”。缺失必需参数降为 warning，来源错误和单位错误仍报告。不能把未知值填0、伪造占位尺寸或将未确认建议画成制造要求。最终交付正式图须预检无 error，人工核对必需条件及报告的 review 项。

六类参数入口及条件见 [parts.md](parts.md)。

### parts.md
# 六类专项：只询问当前特征所需条件

通用规则见 annotation-rules.md。下列是输入/复核范围，不是默认技术要求，也不表示已提供六套自动生成器。

| part_type | 基础参数名 | 条件必需与专项复核 |
|---|---|---|
| shaft | diameters、axial_dimensions | 配合处自身公差、定位功能；有键槽才问槽宽/深/长，有几何控制才问基准与公差项目；移出断面方向 |
| gear | module、teeth、pressure_angle、width、bore | 斜齿再问helix_angle、hand；轮毂与连接结构、精度/检验要求按任务补入required；不默认压力角20°、精度7级或齿顶h11 |
| bearing_seat | interface_dimensions | 已知轴承型号核对接口；设计配合才需load_type、rotation_relation、operating_conditions；不自动给轴承内部公差或默认0级 |
| key_spline | type、specification、connection | 轴槽/毂槽区分；定心方式、槽尺寸及对应标准版本；不将N9/JS9、小径定心等套用于全部键/花键 |
| thread | type、specification、length | 非默认螺距/旋向/多线需pitch、hand、starts；公差、旋合长度及镀层要求按任务补入required；不能默认6g/6H |
| taper | independent_geometry、reference_plane、tolerance_method | 独立参数唯一确定形状，锥度/角度/直径/长度关系校核；给定截面直径与全长直径公差区分 |

`conditions` 支持 helical、design_fit、keyway、datum_control、nonstandard_thread（见 drawing_checks.CONDITIONAL）。更具体的缺项由生成脚本的 required 明示，布尔条件未给不能假设结构不存在。

## 轴

两中心孔与两轴承轴颈是不同基准方案：依据功能和加工/检验过程选用。教材图3-80采用两端中心孔A、B；不能误写成两轴承轴颈。图2-1给定尺寸与图2-2示例外形/标注不同，不混用数值。

轴承轴颈圆度/圆柱度、配合处同轴度/跳动、轴肩垂直度/端面跳动、键槽对称度都是按功能选用的候选，不能全加。第三章第91页明确说明后续若干图为展示项目，不代表实际零件全部需要。

## 齿轮与轴承配合件

齿轮规定画法及参数表需核对相应制图标准；已知m、z不一定足以确定变位、斜齿、齿顶修缘等全部几何。不要把齿面精度、齿坯几何公差和尺寸公差混为一项。

轴承是标准件，常规任务画相配轴/座孔或装配简图，不虚构轴承内部零件图。选择配合需考虑负荷相对套圈的关系；不能只看“轴转/孔不转”就选公差带。

## 键/花键、螺纹、圆锥

轴上键槽以便于测量的 d−t₁ 等形式表达时，所需值必须来自实际规格/标准，不按比例估计；槽宽、槽深、长度、对称度及粗糙度按要求分别核对。

教材第三章把螺纹的中径轴线与齿轮/花键的PD、MD、LD说明分别列出，不能写成“三者一律默认中径”。普通螺纹标记中的省略规则先确定标准和螺纹类型，细牙、左旋、多线等不能丢项。

圆锥先核对 C=(D−d)/L=2tan(α/2)，再按选定给定方式标注；冗余输入不一致应报错。理论正确角度方框不是尺寸公差，基面位置和长度单位必须明确。

### feature-decisions.md
# 标注对象、方向与范围的条件规则

适用于本skill的课程图和改错说明。先判定“版本→对象→项目→公差带→基准→连接→布局”，不要从箭头当前画在哪儿反推技术含义。先读[版本选择与差异](standards.md)；教材出处见[sources.md](sources.md)。下述旧教材方向表仅用于解释对应课程画法，不能代替1182—2018的规则。

## 1. 先分清对象与图线

| 名称 | 含义 | 例子及边界 |
|---|---|---|
| 组成要素 | 构成零件外形的表面，以及表面上的线 | 外圆柱面、孔壁、端面、圆锥素线；教材印刷54页 |
| 导出要素 | 从相应组成要素得到的中心点、中心线、中心平面 | 由孔壁得到孔轴线，由槽的两侧面得到中心平面；不是实物上的一条刻线 |
| 被测要素 | 本项公差所控制的对象 | 可以是组成要素，也可以是导出要素；“被测”不是“表面”的同义词 |
| 基准要素/基准 | 基准要素用于建立基准；基准是用于确定方向或位置的理想参考 | 把φ60孔指定为基准要素，由该孔建立基准轴线B。不要把图上任意点画线直接当成基准 |

“组成/导出”按结构特征分类，“被测/基准”按本项要求中的作用分类，两组不是互斥的四种要素。轴线直线度的对象虽为导出要素，却不因此需要基准。

尺寸线承载尺寸值和终端；尺寸界线把测量边界引到尺寸线；公差指引线连接框格和被测要素；基准连线连接字母框与基准三角形。使用者说“这条直线”时，先识别是哪一类。

## 2. 公差箭头的方向与落点分开判断

**1182—2018优先规则**：按第6章识别指向表面或导出要素，按§7.1的缺省规则及必要的方向要素/平面规定公差带。通常指引线方向本身不定义公差带；TED规定方向的情形除外。圆锥圆度按第15章、§17.4另标方向要素，辅助框格有指向主框格的箭头。径向方案与法向方案须明确选择。轴线两平面公差带还需按§7.3规定定向；φ不是所有轴线的固定前缀。

以下是用户2010版教材印刷57页及表3-3等的方向解释，**只在明确采用该教材画法时使用**。不能把“垂直被测表面”写成全部项目的通则，也不能只转动箭头就宣称满足2018版。

| 情形 | 方向与连接 | 依据/限制 |
|---|---|---|
| 平面平面度等，公差带为两平行平面 | 沿带宽方向，通常垂直被控名义平面；箭头落在其轮廓或延长线上，与尺寸线错开 | 表面控制；教材图3-9、表3-3 |
| 圆柱面的圆度、圆柱度，径向圆跳动 | 径向指示；在轴向视图中垂直轴线，也垂直圆柱素线 | 不因图中有轴线就把其他箭头全部转成径向 |
| 圆锥面的圆度（旧教材示例） | 按相应圆截面的径向指示，在轴向视图中垂直轴线 | 表3-3；2018版须另给方向要素，不能仅靠这根箭头 |
| 圆锥面的斜向圆跳动 | 沿规定检测方向；教材常见方案垂直锥面素线，若明确给定检测角度则按该方向 | 印刷81页；不能简单改成径向 |
| 端面圆跳动 | 轴向指示，平行回转轴线、垂直名义端面 | 印刷81页 |
| 孔/轴的轴线、槽的中心平面 | 指引箭头与相应尺寸线对齐，借尺寸识别导出要素；方向相同可共用尺寸箭头 | 图3-10。普通直径尺寸在轴向视图中垂直轴线，但不能因此把箭尖直接画在任意中心线上 |
| 圆锥轴线 | 按圆锥相应尺寸识别轴线；按教材图3-11处理，必要时补空白尺寸线 | 不能套用圆锥表面的法向箭头 |

同一要素、同一指示/检测方向的多项要求可叠框共用指引线；不同方向分开。公差带为圆/圆柱才在相应值前加φ；不按“零件是圆的”统一添加。

## 3. 基准连线与尺寸线重合或错开

| 需要建立的基准 | 连接方式 |
|---|---|
| 平面、边线等组成要素形成的基准 | 三角形底边贴对应轮廓或其延长线；与相关尺寸线明显错开，避免误认成中心要素基准 |
| 轴线、中心平面等中心要素形成的基准 | 基准连线与对应尺寸线共线/对齐；不直接指向任意图示中心线 |
| 圆锥轴线基准 | 教材图3-13(c)：连线垂直轴线，三角形的底边/短横线平行圆锥素线；连线与素线不是同一个方向 |

教材图3-13允许基准符号代替其中一个尺寸箭头，是“可以”，不是自动删除箭头的命令。保留普通尺寸箭头时，箭身在尺寸区间内、基准三角形在界线另一侧，避免图形面积重叠；采用替代时核对实际三角形和接触位置。当前课程图优先保留可辨识的普通尺寸双箭头；需要替代/共用时明确每个端点的符号归属，不能把NONE写进预期后自动算合格。

黑色实心三角形是用户已选画法；17851—2022 §7.2.1允许填充或空白三角形。基准代号采用矩形框；§7.2.2不宜使用I、O、Q、X，P允许，不能沿用旧教材的九字母禁用表。基准字母框不是公差框格，连线不要穿入字母框。

## 4. 哪些线伸出，哪些线到连接处结束

| 图线 | 端点规则 |
|---|---|
| 尺寸界线 | 越过尺寸线终端，保留清楚的伸出段。清华出版社制图教材示例为约2 mm；本项目遇到三角形时还应覆盖整个底边并留净距，不能停在底边中点 |
| 轮廓的细实线延长线 | 用于连接基准或公差箭头时，本项目优先使连接点处在短延长线内，避免在三角形底边中点截断；不得改变实际零件几何 |
| 真实零件轮廓 | 在真实边界处结束；不能为了美观把端面或外形任意拉长。要延长的是辅助细实线 |
| 公差/倒角指引线 | 到箭尖与被指位置、框格连接边界为止；不能穿过被测位置，也不能插进框格内部 |
| 基准三角形与字母框之间的连线 | 从三角形尖端连到字母框边界为止；不是本项目要求继续伸出的尺寸界线 |
| 尺寸线 | 与尺寸箭头按原生几何衔接；外置箭头时保留所需外侧线段。不能把尺寸界线的伸出规则套在全部尺寸线上 |
| 轴线/中心线 | 适当伸出零件轮廓，保持规定线型；避开文字、框格和其他符号 |
| 剖面线 | 裁剪在材料边界内，不越过轮廓、孔和槽 |

原生尺寸以DIMEXE控制界线越过尺寸线的长度，DIMEXO控制起点间隙，两者不同。本题采用6 mm是具体布局选择，不是所有图样必须6 mm。允许的界线起点间隙、文字避让和点画线节奏不要误报成漏线。

## 5. 哪些项目有基准

按教材印刷54页表3-1：

| 项目 | 基准要求 |
|---|---|
| 直线度、平面度、圆度、圆柱度 | 主公差框格无定位基准；不能给孔轴线直线度随意加B。2018版辅助相交/定向平面或方向要素可引用基准规定方向，应与主框格区分 |
| 平行度、垂直度、倾斜度 | 有基准，用来确定方向 |
| 同轴度/同心度、对称度 | 有基准，用来确定相对位置 |
| 圆跳动、全跳动 | 有基准，建立回转基准轴线 |
| 线轮廓度、面轮廓度 | 有或无；依规范是否控制相对基准的方向/位置判断 |
| 位置度 | 有或无；不能把“位置度”直接翻译成“必须补A/B/C”。须核对完整的理论正确尺寸及成组规范 |

基准是功能、装配、加工和检验方案的选择，不是为了填满框格。缺少功能信息时询问。没有基准的形状公差不等于缺一栏；有基准的项目也不是必须填三个字母。

## 6. 尺寸箭头的内外方向

“内/外”以下均相对两条尺寸界线之间的测量区间，不是相对零件材料：

```text
箭身内置：   |◀────────▶|      从区间内指向两侧界线
箭身外置： ──▶|        |◀──    从区间外指向两侧界线
```

1. 两箭头与完整尺寸文字组有空间时，通常箭身内置。
2. 文字放不下但箭头放得下，可以文字外置、箭头内置；不是“文字外置必然箭头外置”。
3. 箭头也放不下时采用外置箭身、尖端朝向尺寸界线；本项目在自动选择窄尺寸/外置文字方案时，沿用用户确认的此项默认。
4. 按实际字体、偏差堆叠、符号、箭头大小和净距判断，不能只数文字字符。箭头位置与文字位置分别处理。
5. 上述是普通线性尺寸的两端规则。半径、单独指引线、只画一半的对称图形等另按其规则处理，不能一律检查为两个普通箭头。

依据：清华出版社《画法几何及机械制图》试读§1.1.5、表1-5，链接见sources。原用户索引中“箭头外置、从内向外指”的表述方向混淆，不沿用。

## 7. 倒角的几何、标注和覆盖范围

- 45°倒角可用`2×45°`，2是倒角的线性尺寸，不是数量；C2也是45°倒角的简写。非45°倒角用明确的线性尺寸及角度表达，不把所有倒角都写成C。
- 连续圆周棱边（轴端外圆或孔口）倒角后形成一整圈倒角面；主视图上下两处轮廓都要表现对应斜边，一处清楚标注可说明同一圈，不必上下各重复标一次。
- 一圈倒角不自动包括另一轴端、孔口内圈、轴肩另一棱边、键槽或其他独立边；这些是不同的倒角范围。棱柱上一个局部角也不能自动推成“全周”。
- 要求多个独立边全部倒角时，每个范围必须被完整覆盖：逐处标注，或对相同倒角用明确数量/分组引出合注，或以范围清楚的统一技术要求表示；不是强制每个角各画一根箭头。
- 需要表达的倒角轮廓应与规定范围一致，不能只改标注文字却保留错误尖角。采用允许的简化画法时说明依据；本项目的旋转轴主视图不得一侧有斜边、另一侧仍保留原尖角。
- “全部”仍须明确大小、角度及范围。只有“全部倒角”但没有尺寸时，不能自动补C1或C2。示例文字“未注倒角0.5×45°”仅说明表达形式，不能作为用户零件默认技术要求。
- 本项目带箭头的倒角引出段沿真实倒角直线的延长线，箭头指向真实倒角；尺寸文字放在水平段上方。这是已确认默认，不把标准允许的其他明确尺寸注法一概判错。
- 倒角应裁剪原两条轮廓并生成真实斜边；尺寸界线从实际轮廓取落点，不能继续指向已被切掉的旧角点。特殊规定的理论交点尺寸另按规定表达，不与错误的悬空界线混同。

# 通用标注规则与项目默认

依据位置见 [sources.md](sources.md)。以下区分教材规则和项目偏好；采用其他标准版本时重新核对，不能将一套图样宣布为普遍唯一合法画法。

## 字体与尺寸

数字/拉丁文字 CAD_TEXT 默认 ISOCP（isocp___.ttf），中文 CAD_CJK 默认仿宋（simfang.ttf）。字体必须存在，可使用 CAD_FONT_DIRS 指定目录；不附带商用字体，不静默替换。用 typography.add_text，避免遗漏 style。普通文字3.5 mm，偏差2.5 mm；打印缩放时先确定最终纸面字号，模型尺寸始终真实毫米。

上下偏差堆叠、零写0；整体测量占用宽度，外移时不能拆开公称值与偏差、改变精度或缩字。理论正确尺寸的方框与几何公差框格含义不同，不混用。

`dim_linear(..., arrows="auto"|"inside"|"outside", text_location=...)`：文字位置与箭头独立。auto 对窄尺寸/外置文字采用本项目偏好的箭身外置、尖端朝内；明确教材示例可传 inside，箭头确实放不下则报错。原生 DIMENSION 保留测量和偏差，禁止生成后单独旋转匿名块箭头修外观。共享箭头/基准替代箭头用 suppress_arrow，线仍到位。

不能遗漏箭头、留非预期空挡或文字/引线重叠。允许规范规定的文字避让、尺寸界线起点间隙、点画线节奏。尺寸线与尺寸界线不是同一对象，不把一切线交点都当作错误。

本示例按用户选择用extension_gap=0贴轮廓起线；函数默认1 mm保留既有调用的起点间隙。文字净距按最终堆叠MTEXT真实高度计算，测量和绘制使用相同偏差字号精度。水平尺寸组在线上，竖直尺寸组在线左；不能只将字的插入点放在线旁而不管整个字组范围。

## 几何公差：控制什么，连接什么

先确定功能、组成/导出要素、公差带形状、基准，再选择位置。不能仅凭零件外形填公差项目。

- 表面/轮廓：连接轮廓或延长线，与尺寸线明显错开。
- 轴线/中心平面：与相应尺寸线对齐，方向一致可合用一个箭头；不能直接指任意中心线。
- 尺寸线可以延长后转向接框格。尺寸及偏差沿尺寸线延伸部分标注，公差值位于框格内，不给同一点重复加箭头。
- 公差值前 φ/Sφ 由圆/圆柱/球形公差带决定。圆度、圆柱度、平面度、对称度、圆跳动的带宽不是直径；圆柱零件不意味着所有项目加φ。
- 同一要素、同测量方向可叠框共线；测量方向不同分开。共同公差带用适用规则中的 CZ，不能以框格外文字替代。
- 框格水平左→右，竖直下→上；特征、值及修饰符、最多三个有次序基准。A-B公共基准一格，A、B顺序基准分格。
- E 包容要求随尺寸标注；M/L随被测值或基准字母的位置含义不同，不能挪位。含修饰符的复杂情况核对来源后绘制。

本项目默认框格左边中点引出、末段水平；直线或一次转折优先。教材规定从一端垂直引出、最多两次转折，并非只能左边。先移动框格/文字解决拥挤，不自动绕行多段。

基准默认黑色实心三角形，底边贴边界，尖端向外接字母框；教材说明空白三角形与涂黑同义。表面基准与尺寸线错开，轴线基准与尺寸线对齐，可替代尺寸箭头。禁止用普通箭头代替三角形；不要直接标在任意轴线上。中心孔基准须按相应示例处理，不能一概禁止端点位置。

本项目要求用于连接基准/公差箭头的轮廓延长线和尺寸界线，越过连接位置再保留清晰伸出量；基准三角形处须覆盖整个底边，不能画到其底边中点就结束。原生尺寸通过`doc.dimstyles.get("CAD_MM").dxf.dimexe`控制尺寸界线越过尺寸线的长度，按符号大小与净距选值；不要混用控制起点间隙的dimexo，也不要延长字母框的连接线来冒充界线伸出。保存后检查实际LINE终点，而非只检查样式参数。

上述伸出要求不适用于所有直线：真实轮廓止于零件边界，指引线止于箭尖/框格边界，基准连线止于字母框边界，剖面线止于材料边界；中心线应避让文字。示例采用6 mm不作为全部图样的固定值。

## 倒角、粗糙度、移出断面

- 45°倒角可采用 `2×45°` 形式；非45°须给出相应尺寸与角度。本项目默认引线有箭头段与真实倒角所在直线共线，沿其延长线布置，箭头指向倒角，文字在水平段上方；不当作国标唯一画法。未知倒角几何不验证为正确。
- 对旋转轴端的同一连续圆周棱边，整圈倒角在主视图上下两条轮廓都应表现相应斜边，共用一次清楚的标注。`2×45°`中的2是尺寸，不是倒角数量；不自动扩展到另一轴端、孔口内圈或棱柱上的其他角。
- 要求所有指定棱边倒角时，用逐处、明确数量/分组合注或范围明确的统一技术要求覆盖全部范围，不强制每个角各画一根箭头；大小、角度或范围缺失时不得自动补造。
- 课程粗糙度按教材图5-10：幅度参数在长横线下方，加工方法等在上方；符号尖端从材料外接表面。材料去除符号的短横线不是实心三角。旋转时符号和文字一起处理，避免与轮廓相撞。
- C—C、D—D断面与对应剖切/投射方向一致，中心线平行对应方向并伸出轮廓；键槽等断面保留实际材料边界，剖面线裁剪。仅按功能增加所需几何公差。

剖切组两端各写C/D，断面名称写C-C/D-D并居中；上下字母及符号按轴线镜像布置。断面从真实剖切定位图元投射，竖向对应时横坐标相同，不能仅检查两根线平行。粗糙度在允许表面范围内另选位置，与剖切标识预留净距。标题栏及周围净空不得放入视图、框格或引线。

## 尺寸关系与公差协调

先直接标注装配定位、配合与功能长度，再考虑制造/检验及总长。总长与全部分段不能同时作为独立要求；有明确用途的参考尺寸可括号表达，不能靠括号掩盖相互矛盾的数值。

不自动删最短尺寸。功能角色未知时询问；已确认非功能且可推导的尺寸可省略。小尺寸在内、大尺寸在外，同层间距按纸面字号和布局统一。

尺寸链名义关系与公差运算分开。`derive_difference` 给出最坏情况差值区间，不代替工艺公差分配，也不默认采用统计法。

不能无条件套“形状<定向<定位<尺寸”。教材§3.5.1给出相同要素等条件下的协调要求与经验范围，先检验适用条件。未注尺寸/几何公差标准、等级和适用项目需明确给定，不默认1804-m或1184-H。

# 检查与改错

## 输入与动作

- 有生成脚本：优先修生成逻辑，在新输出位置重新生成，避免只改匿名尺寸块。
- 先记录采用的标准版本，按[standards.md](standards.md)核对适用差异。圆锥圆度的方向要素框格、辅助框格基准引用、版本间允许的替代形式须人工核实，不能由现有主框格的“形状公差无基准”检查直接判错。
- 有DXF：只读检查后在修订副本修改，保留原件。
- 只有截图：标出问题和依据；未知尺寸/公差不能从比例重建。需要对应DXF或参数才能精确修改。

`python scripts/drawing_checks.py input.dxf --spec parameters.json --report report.json`

`audit_annotations(msp)` 保留原来的字符串列表；`audit_drawing(msp, chains=...)` 返回包含 code、severity、entity、message、basis、suggestion 的问题。error必须修复，review需人工给依据，不能当作通过。没有给尺寸链/要素关系时会列出复核项。

`mark_annotation` 将辅助函数的说明保存在CAD_CODER XDATA，随DXF保存。导入外部文件不能凭线段猜这些信息。feature_control_frame的feature可提供kind=surface及surface_line、可选size_line；或kind=derived及size_line。目标点由target指定。

## 防止尺寸箭头被错误抑制

验收要求必须独立于生成样式。不能因为脚本设置了NONE并记录blank_ends，就自动认定该端允许没有普通尺寸箭头。先明确各端保留普通箭头，还是采用有依据的基准替代/共用；后者须另查实际替代图元、落点及方向。

对要求普通双箭头的直线尺寸，重新读取DXF后执行：

```python
required = {dim.dxf.handle: (1, 2) for dim in msp.query("DIMENSION")}
issues = audit_annotations(msp, required_arrows=required)
if issues:
    raise ValueError("\n".join(issues))
```

此示例仅适用于这些尺寸均已明确要求普通双箭头的图。合法替代端不要机械列为普通箭头要求。`audit_required_arrows(dim, required_ends=(1,2))` 检查实际端点上的箭头块、样式抑制、隐藏图层及空几何，不接受blank_ends豁免。它是生成逻辑检查，不能替代最终渲染和CAD软件内复核。回归测试应故意抑制或删除一个箭头，确认出图会被阻止；不要仅测试脚本自己生成的正常文件。

## 自动覆盖与边界

- 输入：缺项、来源字段、提议未确认、单位、上下偏差顺序。
- 原生直线尺寸：箭头实体、端部连接及非文字避让的内部断线；其他尺寸类型仍需视觉检查。
- 尺寸落点：传入witness_geometry时，检查defpoint2/defpoint3是否在声明的实际直线轮廓上。倒角前的虚拟角点不得冒充实际轮廓点。只把起点间隙设0，不能补偿错误的几何落点。
- 文字：TEXT按实际字形、MTEXT按完整分数/堆叠排版计算边界；检查文字互相重叠、轮廓/引线/箭头等穿过文字净空。尺寸MTEXT显式存储真实宽度，避免将堆叠公差摊平估宽导致错位。
- 整组布局：CAD_LAYOUT记录框格、粗糙度、剖切标识及标题栏范围；检查标题栏禁入、其他标注的线穿框、粗糙度与剖切组共线/交叉、独立引出线交叉。不存在通用全图自动求解器，复杂线型和未覆盖的关联仍需视觉复核。
- 剖切与断面：从实际图元检查共线，不仅检查方向平行；检查上下字母/符号镜像及断面名称居中。不要用两个写死的相同方向向量冒充关联检查。
- 文字方向：完整尺寸组应在水平线上方/竖直线左侧，检查净空；只有显式text_side=native才保留调用者选择的其他布局。
- 已标记框格：公差带前缀、部分项目的基准要求、基准存在性、表面/导出要素连接。
- 已声明尺寸链：循环冗余、矛盾；不给链就不猜功能。
- 倒角：辅助函数建立时检查真实倒角边共线性；有元数据的后续文件再次检查。
- 已标记紧固件：`audit_fasteners(msp)` 对带 `thread_end`/`fastener_hex_side` 元数据的图元检查结构（缺少图元、粗/细角色、半径、约270°细弧、中心偏移、sibling 互指与重复角色、外轮廓闭合与轴对齐、两面边按边界 e/4 投影位置、同组关联）。粗/细按有效线宽判断（实体覆盖优先、BYLAYER 取图层、BYBLOCK 走 review），默认 0.50/0.25 mm 不是唯一合法笔宽。只按显式 `major/minor` 校验，不按比例推断规格；不改变技术数据。中心线只记录不判定。已标记但缺关联的旧图元输出 review 供人工复核，不猜配对；完全未标记的外来DXF不推断螺栓/螺母。

框格文字宽度由实际字体计算，原始单位/偏差数据不因布局修改。任意外来DXF、不同标准版本、所有14项公差及复杂修饰符的完整语义，仍需有依据的人工复核。空问题列表不等于全部合规。

## 九类截图的回归要求

起线留白与意外断线分开；字母不能压倒角引线；外置数字在线上方；竖直数字在线左侧且箭头齐全；剖切与粗糙度分区；上下标识镜像；缺箭头与明确基准替代分开；断面与剖切位置共线；框格/引线避开标题栏。test_layout.py通过人为移动/破坏图元验证检查能报错，正常连接不得误报。

## 改错权限

字体、文字位置、明确的断线等不改变技术含义的修复可执行。公差值、配合、基准方案及功能尺寸增删须来源或确认；禁止自动“修正”为经验值。

`repair_dxf(source, output)` 提供可重复的字体样式修复，要求不同且未占用的输出路径，输出修改记录；其他问题回到脚本或有依据地编辑。不能把诊断报告称为全部问题已自动修复。修后重新开DXF、运行检查并看整图/局部。

## 尺寸链数据

```python
chains = {"shaft_axis": [
    {"start": "left", "end": "shoulder", "value": 40, "function": "locating"},
    {"start": "second_shoulder", "end": "right", "value": 35, "function": "coupling"},
    {"start": "left", "end": "right", "value": 125, "function": "overall"},
]}
```

节点是同一方向尺寸位置；value=end−start的有符号距离。参考尺寸用reference=True，不作独立制造约束，但仍校核矛盾。check_dimension_chain只报告，不自动挑选删哪个功能环。derive_difference用最坏情况区间计算，不能省掉输入偏差来源。

### standards.md
# 标准版本选择与已核实差异

## 选择顺序

1. 题目、合同或用户明确指定版本时，按指定版本处理；不得自动将题设换成新版。本次题目明确指定GB/T 1182—2018。
2. 没有说明版本时，查询官方目录，默认采用交付时**已实施且现行的最新版**。已发布未实施、征求意见稿、废止标准不能冒充默认现行依据；需要并列说明时单列。
3. 阅读所采用标准的规范性引用文件：注日期的引用按该日期版本；不注日期的引用按其最新版本及修改单。括号里的采标信息年份不等于将不注日期引用改成注日期引用。
4. 课程资料用于解释和比对；未明确指定旧版时，教材出版年份、旧示例图不覆盖默认现行规则。教师指定教材画法与题目指定标准冲突时，明确列出冲突，不混成一套规则。
5. 记录标准编号、版次、实施/状态核查日、具体条款/图号和资料取得方式。只有目录时只能证明状态，不能声称已核实正文。项目偏好另列。

## 本次核实（2026-11-26）

GB/T 1182—2018现行，2019-04-01实施；GB/T 17851—2022现行，2023-04-01实施。1182—2018第2章对GB/T 17851为不注日期引用，因此本项目当前配套采用17851—2022；若任务锁定历史标准体系，另行说明。

| 争议点 | 已核对的旧标准/旧教材 | 本次现行依据与处理 |
|---|---|---|
| 指引线方向是否直接规定公差带 | 1182—2008 §8.1注已说明指引线箭头方向不影响公差定义；用户2010版教材印刷57页概括为带宽方向或径向 | 1182—2018 §7.1同样说明通常指引线方向本身不影响公差带定义；用TED规定指引线和带宽方向的情形除外。不能把该一般原则误称为2018年才新增 |

## 圆锥圆度的方向要素选择

圆锥孔圆度主框格为`○ | 0.005`。若设计明确选择径向方案，可在右侧另接`⊥ | P`方向要素框格（带左向箭头），表示带宽方向垂直由小圆柱孔建立的基准轴线P；该P仅作方向参考。此为一种设计选择，不能在改错时未经依据就替换原有的法向控制意图。锥面法向方案按§15.4及图100另给对应基准要素与方向符号，两套含义不能混用。

用户随后提供的本题课程答案选择的是**锥面法向方案**：小圆柱孔建立基准轴线B，锥面标识为C；圆度主框格`○ | 0.005`右侧的方向要素框格为`跳动方向符号 | C`。该符号在辅助框格中用于指示垂直于被测锥面的方向，不把圆度项目改成圆跳动。复绘本题时采用这张答案的方案，不再自行替换为径向方案。
